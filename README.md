# Tanganyika – Sky Wings Academy

Academic Management System
Primary Wing (Reception – Year 6) · Secondary Wing (Year 7 – Year 13)

**Developed by Rasul A. Mngazija**

## Roles
- **Super Admin** — Full system, both wings.
- **Head Teacher** — Locked to own wing (`headprimary` → Primary, `headsecondary` → Secondary).
- **Teacher** — Only assigned classes/subjects. Can teach in both wings.
- **Homeroom Teacher** — Additionally enters Remarks & Character and views reports — only for their homeroom class.

## Install as App
- Android (Chrome): tap **Install App**
- iOS (Safari): Share → **Add to Home Screen**
- Desktop: click **Install App** in the top bar

## Hosting
Static PWA. Host on GitHub Pages, Netlify, Vercel, or any static host.
